Design System

This portfolio.

The colors, type, spacing, and components behind this site. Every swatch below is the actual CSS it ships with — not a mock style tile.

Color

One ink, one cream, one accent that has to earn it.

Almost everything on this site is ink text on a warm off-white background. Coral only shows up for things that are genuinely interactive or genuinely mine — links, the nav cursor, active states — never as decoration.

Coral and coral-text are the same color at two different weights — full-strength on a dark background where it has contrast to spare, a darker shade wherever it sits on the light cream so small text still clears accessible contrast.

Typography

Inter, and a lot of restraint on weight.

One typeface for the entire site — headings and body both, just different weights and sizes. No display font, no serif anywhere except the one intentional exception in the Still case study's own scoped styles.

Spacing & layout

One column width, reused everywhere.

Every page shares the same horizontal rhythm — 5% side padding on .wrap, no hard-coded max-width, so the layout scales with the actual browser window instead of stopping short on a wide monitor. Case studies use a slightly narrower 1040px content column for readability.

Borders & dividers

Two weights of hairline, nothing heavier.

Nothing on this site uses a border thicker than 1.5px, and most of what looks like structure is actually spacing and color doing the work — these two are for the genuine cases that need a literal line: a divider between sections, a card outline, a subtle hover fill.

Shadows

Contextual, not a fixed scale.

There's no elevation system with named steps here — each shadow is tuned to whatever it's lifting off the page. A poster shifting slightly on hover gets a soft neutral shadow; a dark button getting a coral hover gets a shadow tinted to match, so the glow reads as light from the color, not a generic drop shadow.

Neutral lift — movie posters, image hovers
0 6px 18px rgba(12,12,12,.12)
Coral glow — primary button hover
0 8px 24px rgba(15,163,127,.28)
Motion

Two curves, used on purpose.

Nearly every transition on the site reaches for the same settling curve — a quick start that eases into place, never linear. A springier curve is reserved for exactly one kind of moment: things that get flipped or picked, like a toggle switch or a selected filter pill.

--ease · 45 uses
cubic-bezier(.16, 1, .3, 1)
--spring · 3 uses
cubic-bezier(.175, .885, .32, 1.275)

Hover either track to re-run it. The fade-up-as-you-scroll effect you've seen on every page runs on --ease too — it's the same curve, just applied to opacity and position instead of a hover state.

Iconography

Line icons only — stroke, never fill.

Every icon on the site is drawn the same way: roughly 2px stroke weight, rounded caps and joins, no filled shapes. No icon library — these are hand-drawn paths, kept deliberately simple so they read at 13–16px without getting muddy.

Provenance markers

A small badge, not a label that shouts.

Every card on the work grid gets the same small circular marker in the corner — the company logo for an internship, a graduation cap for school work, a lightning bolt for something vibe-coded on my own. Same size, same position, every time, so provenance reads at a glance without needing its own paragraph.

Voice

One blinking cursor, opening and closing the site.

The nav mark isn't just "bl" — it's "bl" with a cursor that blinks like it's waiting for input. The footer closes every page on a terminal line signing off. Same cursor-blink animation, same idea, used exactly twice: once to open the site, once to close it. That's the whole personality budget — small and specific, not scattered everywhere.
